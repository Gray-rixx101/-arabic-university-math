# أثر · متتبع العادات

تطبيق ويب (PWA) بالعربية لتتبع العادات على طريقة لوحة مساهمات GitHub، مبني على أفكار كتاب «العادات الذرية».

- **عادات أبنيها**: سجّل الإنجاز يوميًا، مع أهداف متعددة (مثل 8 أكواب ماء أو 20 صفحة).
- **عادات أتركها**: كل يوم يُحسب نظيفًا تلقائيًا، وتسجّل الزلّات فقط، مع عدّاد «يوم بدون».
- خطة القوانين الأربعة (والقوانين المعكوسة للإقلاع)، والهوية، والعادة البديلة.
- ثلاث طرق عرض، وصفحة لكل عادة بتقويم شهري وملاحظات يومية، وإحصاءات سنوية.
- تذكيرات تُصدَّر إلى تقويم iPhone، ونسخ احتياطي واستعادة بملف JSON.
- يعمل بدون إنترنت، وكل البيانات تبقى على الجهاز.

## التثبيت على iPhone

1. افتح رابط التطبيق في **Safari**.
2. اضغط زر **المشاركة** ثم **«إضافة إلى الشاشة الرئيسية»**.

## التشغيل محليًا

```bash
cd habits && python3 -m http.server 8000
```
