# مقدمة إلى المتجهات — Vectors

## الفكرة الأساسية

المتجه (Vector) كمية لها مقدار واتجاه. في المستوى يمكن كتابته كزوج مرتب:

`v = (x, y)`

يمثل `x` التغير الأفقي، ويمثل `y` التغير الرأسي.

## طول المتجه — Magnitude

باستخدام نظرية فيثاغورس:

`||v|| = sqrt(x^2 + y^2)`

### مثال

إذا كان `v = (3, 4)` فإن:

`||v|| = sqrt(3^2 + 4^2) = sqrt(25) = 5`

## تمرين

احسب طول المتجه `w = (5, 12)`.

الحل: `13`، لأن `sqrt(25 + 144) = sqrt(169) = 13`.
